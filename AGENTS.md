## Планы разработки и тестирования

### Требования к планам

- **ОБЯЗАТЕЛЬНО** использовать стандартизированный шаблон из `.templates/DEVELOPMENT_PLAN_TEMPLATE.md`
- План должен быть подробным и разбит на фазы выполнения
- Одна фаза плана должна помещаться в один контекст используемого AI
- После выполнения плана, он должен отмечаться как завершенный в файле плана
- Планы сохранять в директорию `plans/`

### Ресурсы для создания планов

- **Шаблон**: `.templates/DEVELOPMENT_PLAN_TEMPLATE.md` - базовый шаблон с инструкциями
- **Пример**: `.templates/DEVELOPMENT_PLAN_EXAMPLE.md` - заполненный пример для референса
- **Руководство**: `.templates/TEMPLATE_GUIDE.md` - подробное руководство по использованию шаблона

### Структура плана

План должен включать:
- Метаданные (версия, даты, статус)
- История версий (semver)
- Текущий статус (для AI возобновления работы)
- Оглавление с чекбоксами и навигацией
- Фазы с явными зависимостями
- Подпункты с артефактами и ссылками
- Чеклисты критериев завершения

### Workflow

1. Скопировать шаблон: `cp .templates/DEVELOPMENT_PLAN_TEMPLATE.md plans/PLAN_NAME.md`
2. Заполнить метаданные и фазы
3. Обновлять "Текущий статус" при переходе между подпунктами
4. Отмечать чекбоксы по мере выполнения
5. Создавать новую версию плана при изменении структуры
